Before you run: generate a personal API key at the Riot Developer Portal (developer.riotgames.com) — it expires every 24h and needs regenerating. It's only sent to your own local proxy server, which forwards it straight to Riot; it isn't stored anywhere and won't survive a page reload.
Backend required: this page talks to a small local server (node server.js) which proxies the Riot API calls and holds the Anthropic key server-side. If RUN fails immediately, make sure the server is running and you're viewing this page at its localhost URL (not opened as a bare file).
Getting "Forbidden" (403)? Riot restricts VALORANT account/match endpoints to keys with the VALORANT API product enabled — a default personal key often only covers League/TFT. Check product access for your key at developer.riotgames.com, and remember personal keys expire every 24h.
